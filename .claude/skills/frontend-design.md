# Frontend Design Skill Overview

This skill enables creation of distinctive, production-grade web interfaces that avoid generic aesthetics. The guidance emphasizes **intentional design direction** over intensity—whether maximalist or minimalist, the key is coherent execution.

## Core Principles

**Design Thinking**: Understand purpose, audience, tone, and constraints before coding. Choose a bold aesthetic direction (brutalist, retro-futuristic, organic, luxury, etc.) and commit to it with precision.

**Aesthetics Focus**:
- Typography with distinctive, characterful fonts rather than generic defaults
- Cohesive color palettes using CSS variables with dominant colors and sharp accents
- Motion through CSS animations and scroll-triggered effects
- Unexpected spatial composition: asymmetry, overlap, grid-breaking elements
- Atmospheric details like gradients, textures, and layered transparencies

## Critical Guidelines

Avoid "AI slop" by rejecting predictable choices like overused sans-serifs (Inter, Roboto), clichéd purple gradients, cookie-cutter layouts, and generic patterns. Designs should vary contextually and feel genuinely crafted rather than templated.

**Match complexity to vision**: Maximalist designs warrant elaborate code with extensive effects; minimalist designs demand restraint and precision in spacing and typography.

The skill prioritizes working, functional code paired with visual memorability and context-specific character across all implementations.
